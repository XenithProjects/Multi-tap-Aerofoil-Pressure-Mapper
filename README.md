# Multi-tap-Aerofoil-Pressure-Mapper
An open-source Multi-tap Aerofoil Pressure Mapper for a NACA 2412 Aerofoil using an ESP32, a PCA9548A I2C Multiplexer and five Sensirion SDP810-500Pa differential pressure sensors.
Adaptable to other aerofoil designs.
